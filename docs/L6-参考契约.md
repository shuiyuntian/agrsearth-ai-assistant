# L6 参考契约

## 6.1 CapabilityContext API 速查

完整定义：`packages/sdk-types/src/index.ts`（`import type { CapabilityContext, CapabilityPackage, CapabilityManifest, FloatingPanelOpts, FloatingPanelHandle } from '@agrsearth/sdk-types'`）。

| 成员 | 签名要点 | 备注 |
|:---|:---|:---|
| viewer | `readonly any` | 直接暴露；直加实体的唯一合法场景=无（用 ctx.entities） |
| entities | `add/remove/removeAll/getById` | **ADR-006 分组隔离**，停用整组隐藏 |
| dataSources | `add(Promise)/remove/removeAll` | 本包分组 |
| layers | `addImageryLayer/remove/setVisibility/move/setBaseLayer` | setBaseLayer 切底图 |
| primitives | `add/remove/removeAll` | 直加 scene.primitives 须自清理 |
| terrain | `requestSwitch(provider, reason?)` | 多插件仲裁 |
| camera | `flyTo/getPosition/onChange(h, {throttle})` | onChange 返回取消订阅 |
| events | `onScreenSpace(type, handler)` | leftClick/mouseMove/...，返回取消订阅 |
| http | `get/post` | 自动网关前缀 + Bearer |
| notify/confirm/loading | — | success/warning/info/error |
| emit/on | `on(evt, h, {once})` | 返回取消订阅 |
| ui.createPanel | `(FloatingPanelOpts) => FloatingPanelHandle` | handle: show/hide/close/focus/update |
| cleanup | `() => void` | 框架注册的图层/事件回收 |

## 6.2 manifest.json schema（含 components 显式声明段）

> schema 全量契约见 PLUGIN_DEVELOPMENT §4.1（唯一规范本体），本示例为教程节选。

```jsonc
{
  "id": "my-tool",                    // 包唯一 ID（= 目录名，^[a-z0-9-]+$）
  "name": "我的工具",
  "version": "0.1.0",                 // 与 VERSION 文件一致
  "description": "……",
  "type": "extension",                // extension | suite（聚合包）
  "track": "tool",                    // 轨（显式必填、零推断）：tool | system
  "tier": "business",                 // 归属（显式必填）：platform | business
  "delivery": "optional",             // 交付（仅 tool·business 象限用）：bundled | optional；其余象限不填
  "platformVersionRange": "^1.3.0",
  "author": "团队名 <联系邮箱>",
  "icon": "MapLocation",
  "entries": {                        // 球端远程加载入口（发布时 url 回填）
    "esm": { "url": "", "type": "module" },
    "umd": { "url": "", "type": "script" }
  },
  "components": {                     // ★ 显式声明，零推导；缺省 false
    "frontend": true,                 // 球端面板
    "backend": ["my-tool-server"],    // 后端服务 serviceId 数组
    "adminUi": true,                  // 管理面远程页
    "menu": { "enabled": true, "menuPath": "my-tool" },  // 管理面菜单（enabled=true 必须带 menuPath + data/menu.json）
    "data": true                      // 数据资产（data/ 建表种子 SQL、菜单声明 menu.json）
  },
  "backendServices": [                // 与 components.backend[] 对齐
    { "serviceId": "my-tool-server", "name": "…", "required": true,
      "apiPrefix": "/my-tool", "healthEndpoint": "/my-tool/actuator/health",
      "imageSource": "self" }         // self=自构镜像（推导 gis-platform/<track>/<tier>/<pkg>/<svc>）；upstream=开源组件（+image/upstreamImage）
  ],
  "dependsOnPackages": [],            // 跨包依赖区间（可选）
  "defaultConfig": {}
}
```

publish 统一 pre-check（团队可用 `package_precheck` 或 `publish.mjs --check-only` 本地执行；平台发布链同样执行，契约见 PLUGIN_DEVELOPMENT §11.2/§11.10）：
`track`/`tier` 缺失/非法即拒 + 「目录==分类」闸口（仓内路径必须 `extensions/<track>/<tier>/<id>/`）；
components 与包内实际结构不一致即拒（声明 frontend 必须构建出产物等）；tool 轨自建后端 >1 拒发
（体量闸口）；`menu.enabled=true` 而无 `data/menu.json` 拒发（菜单 SQL 通道已废止）；menuId 越出
本包号段服务端 fail-fast；权限对账红灯拒发。声明 menu 但 sys_menu 未注册 → 告警不阻断
（menu-provision 布设后复测）。

## 6.4 常见失败速查

| 现象 | 根因方向 |
|:---|:---|
| registerRemote 报错 | 同 id 重复注册（升 version）；entry URL 不可达 |
| 工具栏无图标 | 清单未拉到（target 不对）/远程加载失败（见 L9） |
| publish 拒发 | track/tier 缺失或非法、目录与分类不符；components 与结构不符；menu.enabled=true 无 data/menu.json；tool 轨自建后端超 1 个 |
| 面板白块 | Element Plus 浅色组件未做深色覆盖（L10-B） |
