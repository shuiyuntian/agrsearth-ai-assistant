# L7 工程规范

## 7.1 分支模型

- 团队仓库（模板仓 fork/拷贝）：`main` 保持与平台模板同步；开发在 `feature/<pkg>-<简述>` 分支；
- 提测即提交 PR（或压缩包）到平台方集成分支，平台方 review 后合入发布分支；
- 禁止直接向 `main` 推半成品；禁止把 `packages/`、`skeletons/` 的模板改动混入提测
  （模板升级由平台方统一下发）。

## 7.2 提交信息

```
<type>(<scope>): <摘要>     # 例 feat(my-tool): 站点列表联动地图
```

type：`feat/fix/docs/style/refactor/test/chore`；scope = 包 id；摘要一句话、祈使句、≤50 字。

## 7.3 文档四必备与版本五处一致

- 四必备：`manifest.json` / `VERSION` / `README.md` / `CHANGELOG.md`（Keep a Changelog 简化格式）；
- 版本五处一致：`VERSION` ↔ `manifest.json` ↔ `frontend/package.json` ↔ `frontend/src/manifest.ts` ↔
  `container/<svc>/build.sh`（bump 全部位，禁止只改一处）；
- `DESIGN.md/REPORT.md` 为可选历史快照，文首必须有状态行。

## 7.4 代码注释头规范（与平台专项 1 联动，验收必查）

所有**代码文件**（ts/js/vue/py/sh/mjs/java/sql…）头部五要素 + 版权行：

```ts
/**
 * 文件作用：<一句话>
 * 作者：<姓名 <邮箱>> 或 <团队名 <联系邮箱>>     // 新文件按实际开发者/团队署名
 * 创建日期：YYYY-MM-DD（北京时间）
 * 版本：<文件级版本，从 1.0.0 起>
 * 修改记录：
 *   - 1.0.0 (YYYY-MM-DD) 初始创建：<要点>
 *
 * 版权所有 (C) 2026 CesiumAI 项目
 */
```

分语言落位：

| 语言 | 头部形态 | 位置 |
|:---|:---|:---|
| ts/js/vue/mjs | `/** */` 块 | 文件首行（.vue 的 SFC 会被当 HTML 解析——**邮箱禁止用尖括号**，写 `作者：张三（zhang@x.com）`） |
| py | 模块 docstring | shebang 之后 |
| sh | `#` 行块 | shebang 之后 |
| java | Javadoc | package 之前 |
| sql | `--` 块 | 文件头 |
| xml/yaml | `<!-- -->` / `#` 注释 | 文件头 |

> 平台存量文件署名统一为 `JasonLee <shuiyuntian@foxmail.com>`；**新文件由实际开发者/团队署名**。
> 三方代码（vendor）头部原样保留，不补不改。

## 7.5 命名与目录

- 包 id：`^[a-z0-9-]+$`，与目录名一致；serviceId 同规则；
- npm 包名仅为 workspace 标识，与分类无关：`@agrscesiumai/<pkg>`，管理页 `@agrscesiumai/<pkg>-admin`
  （历史 `core-`/`ext-` 前缀随 class 退役，不再作为命名依据）；
- 组件镜像命名空间：`localhost:32000/gis-platform/<track>/<tier>/<pkg>/<svc>:<组件版本>`
  （与仓内目录 `extensions/<track>/<tier>/<pkg>/` 同构，publish 按 manifest track/tier 推导登记）；
- 时区：一切排期/日志/注释日期用北京时间（Asia/Shanghai）。

## 7.6 质量红线（评审 grep 项）

- 禁 `viewer.entities.add` / `viewer.entities.remove`（必须用 ctx.entities）；
- 禁产物打进 `vue/vue-router/pinia/element-plus/@element-plus/icons-vue/cesium/echarts`（构建 external）；
- 禁 admin-ui 内 `createApp` / `import.meta.env`；
- 禁仓库内出现密钥（token/密码/key），含测试脚本硬编码；
- 禁 `latest` 镜像 tag（必须钉具体版本）。
