# L4 概念手册

## 4.1 Capability 框架：插件与平台的唯一入口

球端插件不 import 宿主内部模块，一切经 `activate(ctx)` 拿到的 **CapabilityContext**：

```text
ctx.viewer      Cesium Viewer（直接暴露，自行做好资源释放）
ctx.entities    实体增删查——每包独立 CustomDataSource 分组（ADR-006）
ctx.layers      影像图层（addImageryLayer/setBaseLayer/...）
ctx.primitives  Primitive 管理
ctx.terrain     地形切换（带仲裁）
ctx.camera      flyTo/getPosition/onChange（节流）
ctx.events      屏幕空间事件（返回取消订阅函数）
ctx.http        HTTP（自动网关前缀 + 鉴权）
ctx.notify/confirm/loading   全局通知/确认框/遮罩
ctx.emit/on     插件间事件总线
ctx.ui.createPanel           浮动面板（球端 UI 主要载体）
ctx.cleanup()   清理本插件注册到框架的资源
```

完整类型见 `packages/sdk-types/src/index.ts`（`@cesiumai/sdk-types`），速查表见 L6。

## 4.2 生命周期

```text
宿主启动 → 拉远程清单 → registerRemote(manifest, entry)（同 id 重复注册拒绝并报错）
       → 用户点工具条图标 → activate(ctx)   （建面板/画实体/挂事件）
       → 再点（停用）   → deactivate(ctx)    （隐藏面板；组显隐兜底=整组 show=false）
       → 扩展卸载/注销  → destroy(ctx)       （removeEventListener、close 面板、彻底清理）
```

- 远程加载失败仅告警，不影响首屏地图；
- 帧回调/键盘/定时器等所有能触发实体重建的路径，先判挂起态（slice 剖切实例的教训）。

## 4.3 现场分组隔离（ADR-006，评审必查）

- 实体**只走 `ctx.entities`**；`viewer.entities.add(...)` 直加 = 越权写共享场景，
  停用后无法整组隐藏，**验收一票打回**；Primitive 同理只走 `ctx.primitives` 并自清理。
- 组显隐是兜底，不替代插件自身的挂起/恢复逻辑。

## 4.4 管理面远程化（ADR-007）

- 管理页放包内 `admin-ui/`，产物 `admin.es.js/admin.umd.js/style.css` 随包发布；
- 菜单 `component` 写 `remote:<packageId>/<viewPath>`，宿主运行时加载；
- `import request from '@/utils/request'` 原样可用（import map 别名桥）；
- 禁止自建 createApp、禁止 `import.meta.env` 烘焙、禁止 import 宿主内部组件/store。

## 4.5 资源中心与发布通道

- 产物上传到 MinIO bucket（`<track>/<tier>/<packageId>/<version>/...`，scope **直读 manifest 的
  track+tier、零推导**，与镜像命名空间 `gis-platform/<track>/<tier>/<pkg>/<svc>` 同构）；
- resource-manager 登记包/版本/依赖/资源；菜单声明 `data/menu.json` 经 menu-provision 幂等落地；
  `--deploy` 一键安装 k8s-bundle 并按拓扑序滚动组件；
- **发布权在平台方**：团队侧终点是「提测单」（L8）。发布五步制契约见 PLUGIN_DEVELOPMENT §11.2。

## 4.6 系统轨补充概念

- **组件版本轴**：`container/<svc>/VERSION` 存在时镜像 tag 取组件版本，与包版本解耦。
- **多组件拓扑**：`backendServices[].dependsOn` 决定部署/更新顺序。
- **多组件部署惯例**（原「域内衔接三通道」的技术内容，与已撤回的 domain 分组机制无关）：
  包内组件互调走集群内 Service DNS（`http://<service>:<port>`，不经网关）；非密共享配置用
  共享 ConfigMap（`envFrom.configMapRef` 引入）；凭据一律 `secretKeyRef` 引用平台方预建 Secret
  （**只引用不创建**，bundle 内禁 Secret）。用法见 PLUGIN_DEVELOPMENT §2.3/§11.3。
